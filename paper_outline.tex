\begin{abstract}
本文针对中老年人群高血脂症的风险预警及干预方案优化问题，融合中医体质学、血常规体检指标及日常活动能力评分，构建了多维度数学模型。\\[6pt]
\textbf{针对问题1}，构建``Pearson/Spearman相关+组间差异检验+逐步Logistic回归''的三层筛选体系，发现血脂指标（TC、TG、LDL-C、HDL-C）与尿酸对高血脂标签有显著预警能力，但与痰湿质积分的线性关联极弱（调整$R^2\approx0$）。据此将关键指标明确区分为两类：高血脂风险识别指标（TC、TG、LDL-C、HDL-C、尿酸）与痰湿严重程度直接表征指标（痰湿质积分、主体质标签）。进一步引入随机森林模型弥补线性模型在交互效应上的不足。通过多元Logistic回归量化九种体质贡献度，各体质标准化系数均未达显著性水平；随机森林Gini重要性提示阴虚质、湿热质、血瘀质的非线性特征重要性排名靠前，提示体质间可能存在复杂的非线性交互效应。\\[6pt]
\textbf{针对问题2}，针对高血脂标签与血脂指标存在定义同源性的问题，将风险建模拆分为两层：第一层为现症识别模型（血脂指标复现诊断，AUC$\approx0.978$），第二层为治未病预警模型（体质+活动+基础信息，AUC$\approx0.597$）。该AUC反映非血脂指标对高血脂标签的解释力有限，预警模型旨在发病前识别高危人群，而非复现诊断。综合风险评分采用熵权法与专家经验组合赋权，结合统计分位数与临床锚点确定三级阈值。5折交叉验证与ROC分析量化模型区分能力，权重敏感性分析验证分层稳健性；通过条件概率识别核心特征组合。\\[6pt]
\textbf{针对问题3}，建立基于时间序列的离散动态规划模型，将6个月干预过程逐月模拟，实现调理分级随痰湿积分下降而动态自适应降级（``随症加减''），在保证干预效果的同时节约后期过度医疗成本。引入依从性衰减函数刻画老年患者耐受度差异，并开展敏感性分析。求解得到样本ID 1、2、3的月度干预轨迹及全体278例痰湿体质患者的最优方案，总结出``患者特征—最优方案''匹配规律。\\[6pt]
\textbf{关键词：} 高血脂症；中医体质；随机森林；风险分层；动态规划；干预优化
\end{abstract}

\section{问题重述与分析}
% ==========================================================

\subsection{问题背景}
人口老龄化加剧，中老年人群高血脂症发病率攀升，成为心脑血管疾病的重要危险因素。痰湿体质被视为血脂异常最常见的易感体质之一，其病机关键在于脾失健运、水湿内停、痰浊内生~\cite{jin2026tcm,yu2020hyperlipid}。多项流行病学调查表明，痰湿体质在高脂血症患者中的占比可达21\%--28\%，显著高于其他体质类型~\cite{jia2021chengdu,huang2025t2dm}。然而，不同地区的研究结果存在差异：成都地区的调查显示痰湿体质占原发性高脂血症患者的24.7\%~\cite{jia2021chengdu}，深圳2型糖尿病合并血脂异常患者中痰湿体质占比为21.4\%~\cite{huang2025t2dm}，提示地域、人群特征及判定标准均可能影响体质分布。此外，``治未病''思想强调通过体质辨识实现疾病前预警与个性化健康管理~\cite{yao2019preventive,yu2026health}，血清免疫球蛋白和补体角度的研究也为中医体质与动脉硬化的关联提供了实验依据~\cite{wang2025arteriosclerosis}。而日常活动能力直接影响气血运行与膏脂运化~\cite{zhang2025gut}。目前临床筛查单一依赖血常规，缺乏对体质分型与活动能力的综合考量，难以实现``治未病''的精准防控。

\subsection{问题提出}
\begin{enumerate}[label=\textbf{问题\arabic*}]
    \item 从血常规与活动量表中筛选能有效表征痰湿体质严重程度、且预警高血脂发病风险的关键指标；研究九种体质对发病风险的贡献度差异。
    \item 构建融合多维度特征的三级风险预警模型（低/中/高），明确阈值选取依据；识别痰湿体质高风险人群的核心特征组合。
    \item 针对痰湿体质患者，在中医调理原则、身体耐受度及经济成本约束下，构建6个月干预方案优化模型，给出样本ID 1、2、3的最优方案及``患者特征—最优方案''匹配规律。
\end{enumerate}

\subsection{问题分析}
\begin{itemize}
    \item \textbf{问题1}属于特征筛选与归因分析问题。可利用相关性分析与回归模型的显著性检验筛选关键指标；利用Logistic回归系数或优势比(OR)衡量体质贡献度。
    \item \textbf{问题2}属于风险分层与规则挖掘问题。核心是将连续风险概率离散化为三级，需兼顾统计分布与临床意义；核心特征组合可通过条件概率或决策树规则提取。
    \item \textbf{问题3}属于带约束的组合优化问题。决策空间极小（调理分级$\times$活动强度$\times$频率），可用穷举法精确求解；目标是降分最大化与成本可控的双重要求。
\end{itemize}

\section{问题1：关键指标筛选与体质贡献度}
% ==========================================================

\subsection{数据预处理}
原始数据为Excel工作簿，共1000例样本，包含9种体质积分、血常规指标（HDL-C、LDL-C、TG、TC、空腹血糖、血尿酸）、BMI、ADL/IADL量表及年龄、性别等人口学特征。为保证建模质量，预处理分为以下四步：

\textbf{（1）数据整合与变量映射}
原始数据为Excel格式，共1000例样本、36个字段。首先对列名进行标准化映射，将中文字段名转为英文简写以便后续建模。依据题目附表1的编码规则，将性别（0=女，1=男）、年龄组（1=40--49岁至5=80--89岁）等分类变量转为数值型，确保类型一致。

\textbf{（2）方向性血脂异常风险项数构造}
高血脂风险具有明确的单向性：TC、TG、LDL-C升高或HDL-C降低才构成风险。因此，本文采用方向性异常定义，仅将$\text{TC}\!>\!6.2$、$\text{TG}\!>\!1.7$、$\text{LDL\text{-}C}\!>\!3.1$、$\text{HDL\text{-}C}\!<\!1.04$计入血脂异常风险项数，记为$N_{\text{lipid\text{-}risk}}\in\{0,1,2,3,4\}$。血尿酸正常范围存在性别差异（男$208\sim428\,\mu\text{mol/L}$，女$155\sim357\,\mu\text{mol/L}$），因此单独构造血尿酸异常标记$U_{abn}\in\{0,1\}$，不混入血脂异常项数，以保证指标定义的临床准确性。

\textbf{（3）Z-score标准化}
由于血常规指标量纲各异（如TC单位为mmol/L，BMI为kg/m$^2$），直接入模会导致大数量级变量压制小数量级变量。因此，对TC、TG、LDL-C、HDL-C、血糖、尿酸、BMI、ADL、IADL及活动量表总分进行标准化：
\begin{equation}
Z_{ij}=\frac{X_{ij}-\bar{X}_j}{S_j},
\end{equation}
其中$\bar{X}_j$与$S_j$分别为第$j$个变量的样本均值与标准差。

\subsection{关键指标筛选方法}

\subsubsection{相关性分析与组间差异检验}
题目要求筛选的指标需同时满足两个功能：\textbf{表征痰湿体质严重程度}与\textbf{预警高血脂发病风险}。然而，如后文结果所示，本数据集中血常规指标与痰湿质积分的线性关联极弱，而对高血脂标签的预警能力显著。因此，本文不强行将两类功能归于同一组指标，而是从两个目标变量出发分别分析，建立三层筛选体系：

\textbf{（1）Pearson与Spearman相关分析}
针对痰湿质积分（连续变量），分别计算Pearson积矩相关系数（捕捉线性关系）与Spearman秩相关系数（捕捉单调非线性关系）。针对高血脂二分类标签（0/1），计算各指标与标签的Pearson相关系数（等价于点二列相关系数）。

\textbf{（2）组间差异检验（Mann-Whitney U检验）}
由于痰湿质积分在样例数据中与血常规指标的线性相关性极弱（见后文结果），单一相关分析可能遗漏非线性关联。为此，引入基于体质标签的组间差异检验：将样本按主体质是否为痰湿质（体质标签$=5$）分为两组，对各血常规及活动量表指标进行Mann-Whitney U检验。Mann-Whitney U检验作为最强的非参数检验方法之一，不假设总体分布形式，对异常值具有鲁棒性，广泛应用于医学和气候学领域的极端事件检测~\cite{yang1999mann,yu2009mann}。效应量采用秩次相关系数$r=Z/\sqrt{N}$衡量。

\textbf{（3）多元线性回归（控制混杂因素）}
进一步以痰湿质积分为因变量，10项血常规及活动量表指标为自变量，建立多元线性回归模型，通过标准化系数（Beta系数）比较各指标在控制其他变量后的独立贡献。

\subsubsection{逐步Logistic回归}
相关性分析仅能揭示变量间的线性关联，无法排除混杂因素，因此进一步建立Logistic回归模型，通过控制其他变量来识别独立预警指标。在多元Logistic回归分析中，自变量筛选及逐步回归方法的选择直接影响模型稳定性与解释力，已有研究~\cite{xu2016logistic}表明应综合采用向前选择、向后剔除及双向逐步策略，避免单一方向选择遗漏重要变量，同时若将多分类变量当作连续性变量处理会损失信息，甚至漏掉重要危险因素。设$Y\in\{0,1\}$为高血脂标签，$\boldsymbol{X}=(X_1,X_2,\dots,X_k)^T$为候选指标向量，Logistic模型形式为：
\begin{equation}
\ln\frac{P(Y=1|\boldsymbol{X})}{1-P(Y=1|\boldsymbol{X})} = \beta_0 + \sum_{i=1}^{k}\beta_i X_i,
\end{equation}
其中左侧为事件发生比（Odds）的对数，称为logit函数；$\beta_i$表示在控制其他变量后，$X_i$每增加一个单位对logit的边际贡献。

为从高维候选指标中自动筛选最优子集，采用\textbf{前向选择（Forward Selection）}与\textbf{后向剔除（Backward Elimination）}相结合的逐步策略：
\begin{enumerate}
    \item \textbf{前向选择}：从未选变量中找到$p\text{-value}<\alpha_{in}=0.05$的变量，加入模型；
    \item \textbf{后向剔除}：对已选变量进行Wald检验，若某变量$p\text{-value}>\alpha_{out}=0.10$，则将其剔除；
    \item 重复上述两步，直至没有变量可进也没有变量可出，算法收敛。
\end{enumerate}

该策略相比全子集遍历大幅降低了计算量，同时通过双向校验减少了单一方向选择可能遗漏的重要变量。最终保留的变量即为在统计学意义上能够独立预警高血脂的关键指标。

\subsection{九种体质贡献度分析}
中医体质学将人体划分为九种基本类型，不同体质与疾病易感性存在差异，痰湿体质被认为是血脂异常最常见的易感体质之一，其脂代谢异常的病机关键在于脾失健运、痰浊内生~\cite{jin2026tcm}，且肠道菌群角度的研究也为湿性体质人群脂代谢异常提供了微生物学机制解释~\cite{zhang2025gut}。为量化各体质对高血脂发病风险的独立贡献，将9种体质积分同时纳入多元Logistic回归。由于体质积分间可能存在相关性（如痰湿质与湿热质常相伴出现），直接比较原始系数会因量纲差异而产生偏误。因此，先对各体质积分进行Z-score标准化：
\begin{equation}
X_i^* = \frac{X_i-\bar{X}_i}{\sigma_i}, \qquad i=1,2,\dots,9,
\end{equation}
标准化后，各变量均值为0、标准差为1，回归系数$\beta_i^*$可直接比较绝对值大小。

模型形式为：
\begin{equation}
\text{logit}(P) = \beta_0 + \sum_{i=1}^{9}\beta_i^* X_i^*.
\end{equation}

在解释贡献度时，综合考察两项指标：
\begin{itemize}
    \item \textbf{标准化回归系数}$|\beta_i^*|$：反映该体质积分每增加1个标准差，logit的变化幅度；
    \item \textbf{优势比（OR）}$\text{OR}_i=\exp(\beta_i^*)$：反映该体质积分每增加1个标准差，患病优势（Odds）的倍数变化。OR>1表示风险增加，OR<1表示风险降低。
\end{itemize}

然而，传统Logistic回归作为全局线性模型，容易掩盖变量间的非线性交互效应。考虑到体质间的耦合效应（如痰湿质与湿热质常相伴出现），单一Logistic模型可能低估某些体质的实际影响。为此，本文进一步引入\textbf{随机森林（Random Forest）}模型，通过Gini不纯度减少量度量各体质积分的非线性特征重要性，作为Logistic回归的补充验证。随机森林对多重共线性和非线性交互具有天然鲁棒性，其特征重要性排名可揭示线性模型无法捕捉的复杂模式。现有文献对随机森林变量重要性度量进行了系统研究，涵盖最小深度、分裂频次、置换重要性及节点纯度等原理与性能分析~\cite{cao2022rf}，并在高维医学数据中展现了处理多重共线性和噪声变量的优势~\cite{yao2016medical}；特征重要性排序在医学数据挖掘中的稳定性亦得到验证~\cite{huang2020kanonymity}，加权决策树优化进一步提升了重要性度量的精确度~\cite{ma2017rf}，为本文选择随机森林作为非线性补充验证工具提供了方法学支持。

\subsection{问题1结果与分析}

\subsubsection{相关性分析与组间差异检验结果}
表~\ref{tab:corr}展示了各指标与痰湿质积分及高血脂标签的相关系数。在\textbf{预警高血脂}方面，TG、TC的点二列相关系数最高（分别为0.467、0.439，$p\ll0.001$），LDL-C、HDL-C及尿酸也显示出中等强度关联，与临床认知一致，且已有研究表明痰湿体质高脂血症合并抑郁症患者的尿酸水平与痰湿体质及抑郁程度均呈正相关，提示尿酸可能是痰湿体质继发代谢紊乱的重要标志物之一~\cite{min2024phlegm}。然而，在\textbf{表征痰湿体质严重程度}方面，所有血常规及活动量表指标与痰湿质积分的Pearson及Spearman相关系数绝对值均低于0.06，多元线性回归的调整$R^2$仅为$-0.004$，无一指标通过显著性检验；Mann-Whitney U检验亦未发现痰湿体质组与非痰湿体质组在各指标上存在显著分布差异（效应量$|r|<0.05$）。

这一结果提示，\textbf{在本数据集中，痰湿质积分与血生化指标的线性对应关系较弱}，血常规指标更适合作为``痰湿体质是否已继发血脂异常''的下游监测工具；而痰湿体质本身的严重程度可能还需结合中医量表信息综合判断。该发现与成都地区~\cite{jia2021chengdu}及深圳~\cite{huang2025t2dm}的研究结果部分吻合：前者显示痰湿体质与TG、TC水平升高显著相关，但这种相关性在不同年龄段和性别间存在差异；后者则表明痰湿体质与生活方式因素（饮食、运动习惯）的交互效应可能强于单一血生化指标的线性关联。此外，相关综述亦显示高脂血症与痰湿体质的相关性研究受地域、样本来源及判定标准影响较大，不同研究结论存在分歧~\cite{yu2020hyperlipid}。该推断受限于当前数据的横截面设计，后续可引入纵向随访或中医专属标志物（如脂联素、炎症因子）进一步验证。

\subsubsection{逐步回归筛选结果}
逐步Logistic回归在10个候选指标中最终保留5个：TC、TG、HDL-C、尿酸、LDL-C。BMI与活动能力指标因未能通过进入阈值（$p\geq0.05$）而被排除。这表明在控制其他血常规指标后，BMI对高血脂的独立增量信息有限，其效应可能已被血脂指标所吸收。

\subsubsection{体质贡献度分析结果}
标准化后的多元Logistic回归结果如表~\ref{tab:const}所示。值得注意的是，\textbf{九种体质的标准化系数均未达到传统显著性水平}（$p\text{-value}\geq0.12$），提示在同时控制其他体质积分后，单一体质对高血脂的独立边际贡献有限。气虚质（$\beta^*=0.123$）与平和质（$\beta^*=0.083$）系数绝对值相对较大，但所有体质的95\%置信区间均包含0，且$p\text{-value}\geq0.12$，因此\textbf{不能判定某一体质对高血脂风险具有稳定独立贡献}，任何基于系数大小的排序均缺乏统计显著性支撑，不宜做过度解读。

痰湿质系数为负（$\beta^*=-0.008$，$\text{OR}=0.992$，$p=0.919$），这一反直觉现象的可能原因在于：\textbf{体质标签（主体质）与体质积分高度耦合}，当主体质已被标签变量部分解释后，痰湿积分的边际贡献被压缩；此外，样例数据中体质积分与血脂指标的线性关联整体偏弱，也可能导致回归系数不稳定。进一步计算VIF值（表~\ref{tab:const}），九种体质的VIF均在$2.1\sim3.6$之间，远低于5的常用阈值，说明\textbf{多重共线性不是导致体质系数不显著的主要原因}，更可能是数据生成机制中体质积分与高血脂标签关联弱所致。

为弥补线性模型的局限，随机森林模型的Gini重要性结果显示：阴虚质（$12.22\%$）、湿热质（$11.74\%$）、血瘀质（$11.26\%$）排名靠前，而痰湿质（$10.50\%$）处于中等水平。这一非线性排序与Logistic回归系数排序存在明显差异，提示体质间可能存在复杂的非线性交互效应。例如，阴虚质与湿热质的交互、血瘀质与痰湿质的协同等模式，在全局线性模型中被掩盖，而在树模型的局部划分中得以显现。据此，本文结论为：\textbf{九种体质积分对高血脂标签的独立线性贡献均未达显著水平}，但随机森林提示非线性耦合效应存在；痰湿体质仍应作为题目给定的中医机制变量进入风险解释和干预优化，而不宜仅凭回归系数大小判断其风险贡献。

\subsection{两层风险建模框架}

本文发现，高血脂二分类标签与血脂四项异常规则（$\text{TC}\!>\!6.2$、$\text{TG}\!>\!1.7$、$\text{LDL\text{-}C}\!>\!3.1$、$\text{HDL\text{-}C}\!<\!1.04$）的匹配率为100\%，存在定义同源性。若直接使用血脂指标训练预警模型，本质上是``用诊断依据预测诊断结果''，只能实现现症识别，无法体现``治未病''的发病前预警价值。为此，本文将风险建模拆分为\textbf{两层}：

\textbf{第一层：现症识别模型}。以TC、TG、LDL-C、HDL-C、尿酸为特征，训练Logistic回归模型，输出基础发病概率$P_{\text{diag},i}$。该层用于复现血脂异常诊断，不作为真正``发病前预警''，其极高的AUC仅印证血脂指标对确诊标签的决定性作用。

\textbf{第二层：治未病预警模型}。排除血脂指标，以年龄组、性别、吸烟史、饮酒史、BMI、尿酸、血糖、ADL、IADL、九种体质积分及痰湿体质标签为特征，训练Logistic回归模型，输出未病预警概率$P_{\text{pre},i}$。该层在血脂尚未异常时，通过体质与活动能力评估风险，更能体现中医``治未病''思想。已有研究基于数理分析方法对中医体质与高血压风险的关联性进行跟踪预测，表明在排除临床确诊指标后，体质积分与活动能力等前驱因素对慢性病风险仍具有一定的预警价值~\cite{zhou2021hypertension}，其思路与本层模型设计高度一致。

\subsection{综合风险评分构造}

单一维度难以全面刻画高血脂风险。本文在第二层未病预警概率的基础上，融合痰湿体质严重程度与活动能力缺失度，构造四维综合风险评分：
\begin{equation}
R_i = \alpha\cdot P_{\text{pre},i} + \beta\cdot\frac{S_{\text{phlegm}}}{100} + \gamma\cdot\frac{100-M_i}{100} + \delta\cdot I(\text{主体质}=5),
\end{equation}
其中$M_i$为活动量表总分，$I(\cdot)$为指示函数。

权重$\alpha,\beta,\gamma$的确定采用\textbf{组合赋权法}：
\begin{enumerate}
    \item \textbf{熵权法客观赋权}：计算$P_{\text{pre}}$、$S_{\text{phlegm}}/100$、$(100-M)/100$三项指标的信息熵。熵越小（变异越大），信息含量越高，权重越大。经计算，三项指标的信息差异系数分别为$0.0059$、$0.0307$、$0.0106$，归一化后熵权为$(0.125, 0.650, 0.225)$。
    \item \textbf{专家经验主观赋权}：鉴于未病预警概率直接对应临床诊断逻辑，赋予较高权重0.5；痰湿质积分反映中医体质维度，权重0.3；活动能力缺失度为辅助指标，权重0.2。
    \item \textbf{组合融合}：按50\%主观+50\%客观等权融合，再归一化，最终得到$(\alpha,\beta,\gamma)=(0.313, 0.475, 0.213)$。痰湿体质标签修正系数$\delta=0.15$为经验参数。
\end{enumerate}

组合赋权法通过融合客观数据变异与主观专家经验，有效缓解了单一熵权法在指标间冲突性不足时信息量评估片面的问题~\cite{jiang2021entropy}。单纯熵权法仅考虑指标变异程度，而CRITIC法同时考虑指标间的冲突性（相关性），可更全面地反映指标信息量；本文采用的熵权--专家经验组合策略在医学风险评价中具有良好的可操作性与稳定性。为验证权重选取的稳健性，第~\ref{sec:sens}节进行了敏感性分析。

\subsection{三级风险阈值确定}

综合风险评分$R_i$为连续变量。为将其转化为临床可操作的低/中/高三级预警，本文提出\textbf{统计分位数+临床锚定}的双轨制阈值确定方法。已有研究表明阈值点是风险分担安排的重要警示标志，受多因素影响需结合实际业务不断调整~\cite{yang2018risk}；本文借鉴该思想，将统计分位数与临床意义锚点相结合，避免纯数据驱动导致的极端值误判。

\subsubsection{统计分位数法}
分位数法依据样本自身的分布特征划分层级：
\begin{itemize}
    \item 低风险阈值$\theta_L$：取$R_i$的30\%分位数，即评分最低的30\%人群为低风险；
    \item 高风险阈值参考：取$R_i$的75\%分位数（$Q_{0.75}=0.741$），若按此划分则高风险约占25\%。
\end{itemize}

\subsubsection{临床锚定与阈值校准}
为控制基层随访资源，避免高风险人群比例过高，本文将高风险定义为综合评分最高约10\%的人群。计算90\%分位数$Q_{0.90}=0.799$；同时，锚定高风险集（血脂异常且痰湿积分$\geq60$）的评分均值为$0.801$。取两者较大值并兼顾临床可操作性，最终确定：
\begin{equation}
\theta_L=Q_{0.30}=0.447, \qquad \theta_H=0.801.
\end{equation}
其中$\theta_H$为\textbf{高风险控制阈值}，而非75\%分位数。锚定条件同时作为临床复核规则：若某样本被分位数法划为中风险，但满足``血脂异常且痰湿积分$\geq60$''或``血脂正常但痰湿积分$\geq80$且活动能力$<40$''，则建议临床二次评估以防漏判。

\subsection{三层判定规则}

本文将风险判定设计为三层结构，以区分``已确诊''、``未病预警''与``临床复核''：
\begin{equation}
\text{风险等级}_i =
\begin{cases}
\text{低风险}, & R_i < \theta_L \\
\text{中风险}, & \theta_L \leq R_i < \theta_H \\
\text{高风险}, & R_i \geq \theta_H.
\end{cases}
\end{equation}

同时定义临床锚点修正规则：
\begin{equation}
\text{HighRisk}_{\text{anchor}} = I(N_{\text{lipid\text{-}risk}}\!\geq\!1, S_{\text{phlegm}}\!\geq\!60) \lor I(N_{\text{lipid\text{-}risk}}\!=\!0, S_{\text{phlegm}}\!\geq\!80, M\!<\!40).
\end{equation}

\subsection{模型验证：5折分层交叉验证与ROC分析}

为分别量化两层模型的区分能力，本文对两层模型均进行5折分层交叉验证（Stratified K-Fold CV）。交叉验证结合ROC分析是评估医学预测模型泛化能力的标准方案，可有效避免过拟合并量化模型在独立测试集上的区分性能~\cite{hou2022depression}。

\textbf{现症识别模型}：以血脂指标预测高血脂标签，5折CV的AUC均值为$0.978$（各折在$0.966\sim0.994$之间）。AUC极高印证血脂指标对确诊标签的决定性作用，但由于模型输入与诊断标签存在同源性，该结果不能直接等同于发病前预警能力。

\textbf{治未病预警模型}：以体质+活动+基础信息预测高血脂标签，5折CV的AUC均值为$0.597$（各折在$0.542\sim0.650$之间）。该AUC虽低于现症识别模型，但更能反映不用血脂指标时，仅凭体质与活动能力区分高血脂人群的能力。在血脂正常的``灰度人群''中，该模型能将中医体质高危人群有效识别出来（中高风险），体现了``治未病''的预警价值。

    \item 血脂异常风险项数均值1.40，说明新模型的高风险人群不再等同于``血脂异常者''；
    \item 年龄分布较为分散：40--49岁占28.7\%，50--59岁占21.3\%，60--69岁占17.0\%，70--79岁占21.3\%，80--89岁占11.7\%。60--79岁合计占38.3\%，\textbf{并非集中于该年龄段}。
\end{itemize}

\subsection{模型建立与分析}

问题3要求在中医调理原则、身体耐受度及经济成本的多重约束下，为痰湿体质患者制定6个月最优干预方案。中医体质理论以``未病先防''为核心理念，强调因人制宜、辨体施治，在血脂异常的个体化管理中具有独特优势~\cite{yu2026health}。本文将其建模为\textbf{基于时间序列的离散动态规划问题}，核心创新在于：调理分级$x$不再固定为初始积分对应的级别，而是\textbf{每月根据当前痰湿积分动态调整}，实现``随症加减''的自适应降级，在保证干预效果的同时节约后期过度医疗成本。

\subsubsection{决策变量与参数设定}
\begin{itemize}
    \item $x\in\{1,2,3\}$：中医调理分级。根据中医``辨证论治''原则，调理分级必须与痰湿积分区间严格匹配，不可跨级选择。
    \item $y\in\{1,2,3\}$：活动干预强度，对应轻度、中度、重度三档。
    \item $f\in\{1,2,\dots,10\}$：每周训练频率（次/周），受患者时间与体力限制，最多10次。
\end{itemize}

\subsubsection{约束条件}
\textbf{（1）调理分级约束（中医原则）}

中医强调``同病异治、异病同治''，调理方案必须与体质严重程度匹配：
\begin{equation}
x =
\begin{cases}
1, & S \leq 58.5 \\
2, & 58.5 < S < 62 \\
3, & S \geq 62.
\end{cases}
\end{equation}
该约束为硬约束（Hard Constraint），在优化过程中不可违反。上述阈值依据题目附表2的调理分级标准设定：基础调理对应0--58分，中度调理对应59--61分，强化调理对应$\geq$62分。由于动态规划中积分经计算后为小数，本文以58.5和62作为分界点，消除区间间隙。

\textbf{（2）年龄耐受约束}

中老年人群各年龄段的心肺功能、骨骼肌肉状态差异显著，活动强度必须受年龄限制。《老年人国际运动建议：专家共识指南》建议老年运动干预应遵循``低强度起步、渐进式增量''原则，80岁以上高龄患者应以柔韧性和平衡训练为主，避免高强度冲击性运动~\cite{wu2022exercise}；老年人运动处方应用指南亦将运动强度控制在最大心率的60\%--70\%，且需根据体力评定结果动态调整~\cite{wu1994exercise}。具体约束如下：
\begin{equation}
y \leq y_{max}^{age} =
\begin{cases}
3, & A\in\{1,2\}\ (40\sim59\text{岁}) \\
2, & A\in\{3,4\}\ (60\sim79\text{岁}) \\
1, & A=5\ (80\sim89\text{岁}).
\end{cases}
\end{equation}

\textbf{（3）活动能力耐受约束}

ADL（日常生活活动）与IADL（工具性日常生活活动）量表总分$M$直接反映患者的运动耐受能力。即使年龄较轻，若活动能力评分过低，也应降低运动强度以防跌倒或心血管意外：
\begin{equation}
y \leq y_{max}^{mob} =
\begin{cases}
1, & M < 40 \\
2, & 40 \leq M < 60 \\
3, & M \geq 60.
\end{cases}
\end{equation}
综合强度上限取两者最小值：$y \leq \min(y_{max}^{age}, y_{max}^{mob})$。该设计体现了``木桶效应''——患者的活动能力上限由其最弱的生理维度决定。

\textbf{（4）频率约束与成本约束}

每周训练频率必须在合理范围内：$1 \leq f \leq 10$。

由于调理分级$x$每月根据当前积分动态调整，总成本为各月成本之和：
\begin{equation}
\text{Cost} = \sum_{m=1}^{6}\Bigl[C_T\bigl(x_m\bigr) + 4\cdot f\cdot C_A(y)\Bigr] \leq 2000\quad(\text{元}),
\end{equation}
其中$x_m$为第$m$月的调理分级，由该月初的痰湿积分$S_m$决定。

\subsubsection{目标函数与依从性约束}
优化的核心目标是最大程度降低痰湿积分。根据题目假设，每月痰湿积分下降率$r$由活动强度$y$和频率$f$共同决定。但题目给出的线性公式未考虑老年医学中的\textbf{干预疲劳效应}与\textbf{依从性衰减}——对80--89岁或活动能力低下的患者，每周高频干预不仅难以坚持，还可能因过度疲劳导致效果打折甚至引发安全问题。

因此，本文在原始公式基础上引入依从性衰减函数$\eta(f; A, M)$。需要说明的是，以下衰减系数与封顶值是基于老年医学``高龄及低活动能力患者运动耐受有限''的一般性共识所设定的参考参数，旨在反映依从性衰减的定性规律，其精确数值有待临床随访数据进一步标定：
\begin{equation}
r =
\begin{cases}
0, & f < 5 \\
0.03\cdot(y-1) + 0.01\cdot\bigl(\eta(f;A,M)-5\bigr), & f \geq 5
\end{cases},
\end{equation}
其中有效频率$\eta(f;A,M)$为：
\begin{equation}
\eta(f;A,M) =
\begin{cases}
\min\bigl\{5+0.5(f-5),\;6.0\bigr\}, & A=5\ (80\sim89\text{岁}) \\
\min\bigl\{5+0.6(f-5),\;6.2\bigr\}, & M<40 \quad \text{（活动能力低下）} \\
5+0.8(f-5), & A\in\{3,4\}\ (60\sim79\text{岁}) \\
f, & A\in\{1,2\}\ \text{且}\ M\geq40
\end{cases}.
\end{equation}

该设计的临床依据为：
\begin{itemize}
    \item \textbf{频率门槛效应}：每周训练少于5次时，积分基本不降，提示运动干预必须达到一定剂量才起效；
    \item \textbf{依从性衰减}：高龄或低活动能力患者超出5次/周的部分，有效频率按比例打折（50\%--80\%），体现生理耐受极限；
    \item \textbf{疲劳封顶}：80--89岁及活动能力低下者的有效频率分别封顶6.0和6.2次/周，即使名义频率$f=10$，实际等效仅约6次，防止模型推荐不切实际的极端方案。
\end{itemize}

每月痰湿积分按几何级数下降：
\begin{equation}
S_{m+1} = S_m \cdot (1-r), \qquad m=1,2,\dots,6,
\end{equation}
取对数后$\ln S_{m+1} = \ln S_m + \ln(1-r)$，可见最小化最终积分等价于最大化月下降率$r$。当多个方案$S_7$（第6个月末）相同时，优先选择总成本较低者。

\subsection{求解方法：穷举法逐月模拟}
对单名患者而言，活动强度$y$的上界由年龄和活动能力共同约束（最多3级），频率$f$取1$\sim$10的整数值，合法组合数极为有限（$\leq30$种）。本文采用\textbf{穷举法逐月模拟}：对每种$(y,f)$组合，模拟6个月的干预过程，每月根据当前痰湿积分重新确定调理分级$x_m$，累计计算总成本。若总成本超过2000元则剔除该组合，否则记录最终积分。在所有合法组合中选取最终积分最小者。

该动态规划方法的优势在于：(1)保证全局最优；(2)实现``随症加减''的自适应降级，如患者第2个月积分降至58以下，调理分级自动从强化（130元/月）降为基础（30元/月），每月节省100元；(3)便于绘制干预历程图，直观展示积分变化轨迹。\textbf{若时间跨度更长或决策空间更大，可进一步升级为带记忆化的递归动态规划或值迭代算法。}

\subsubsection{``患者特征—最优方案''匹配规律}
为揭示不同患者特征与最优方案之间的系统性对应关系，对全部痰湿体质患者（体质标签$=5$，$n=278$）执行动态优化，并按活动能力、年龄组、痰湿积分进行分组统计：

\textbf{（1）活动能力决定强度天花板，频率受依从性约束}

在引入依从性衰减后，最优频率不再无条件拉满至10次/周：
\begin{itemize}
    \item \textbf{活动能力差}（$M<40$）：强度被锁死在1级；依从性衰减使有效频率封顶约6.2次/周，最优名义频率$f^*\approx7.2$次/周，每月下降率$r\approx1.2\%$。
    \item \textbf{活动能力中等}（$40\leq M<60$）：可选2级强度，无频率封顶（40--59岁）或80\%衰减（60--79岁），多数患者$f^*\approx9.5$次/周，$r\approx8\%$。
    \item \textbf{活动能力好}（$M\geq 60$）：$y_{max}^{mob}=3$，但约半数患者选择$y^*=3$（如ID 3），利用动态降级节省的调理费用支撑更高活动强度。
\end{itemize}

\textbf{（2）高龄患者以``稳''为主}

年龄组5（80$\sim$89岁）的患者，$y_{max}^{age}=1$，且依从性衰减最强。最优名义频率$f^*\approx7.0$次/周，实际等效仅约6次/周，总成本通常在900$\sim$1100元之间，体现老年医学``低强度、高安全''原则。

\textbf{（3）动态降级的经济学价值}

动态规划中，调理分级随积分下降自动降级，是高积分患者的重要成本节约机制。以ID 3为例：若采用静态方案（调理分级固定为中度），6个月调理费为480元；动态方案下第2月起降为基础调理，调理费仅$80+5\times30=230$元，节省250元，这些节省转化为更高活动强度的投入。

\textbf{（4）成本—效果分析与边界案例讨论}

ID 1在6个月内仅下降4.47分（降幅7.0\%），干预效果相对有限。这是因为该患者活动能力极低（$M=38<40$），活动强度被锁死在1级，且依从性衰减使有效频率封顶约6.2次/周，每月下降率仅约1.2\%。这提示对于重度功能障碍患者，单纯运动干预效果不足。已有研究表明，理气健脾化痰法干预痰湿体质患者可显著降低Hcy和尿酸水平，其近远期疗效优于单纯运动干预~\cite{duan2021therapy}。因此，模型将ID 1识别为``需结合中药调理或康复训练等综合手段''的边界案例，而非单纯依赖活动干预。

对全部278例痰湿体质患者执行优化后，按\textbf{初始调理分级}统计平均降分与平均成本：
\begin{itemize}
    \item $x=1$（基础调理）：平均降分16.54分，平均成本1215.12元，单位成本降分0.0136分/元；
    \item $x=2$（中度调理）：平均降分16.01分，平均成本1253.91元，单位成本降分0.0128分/元；
    \item $x=3$（强化调理）：平均降分16.48分，平均成本1400.69元，单位成本降分0.0118分/元。
\end{itemize}

三组单位成本降分效果接近，但强化调理组成本最高、单位效益最低。主要原因在于：动态降级机制使高积分患者（$S_0\geq62$）在干预前期快速降至中度或基础调理级别，导致强化调理（130元/月）的持续性投入有限；同时，该组患者中高龄或低活动能力者占比更高，依从性衰减进一步削弱了边际效益。这一现象并非模型缺陷，而是题目给定参数（调理分级月成本差异大、下降率3\%/级）下的自然结果，也提示在临床实践中需权衡``高成本强化调理''与``中低强度持续干预''的经济学合理性。

\section{模型评价与改进}
% ==========================================================

\subsection{模型优点}
\begin{enumerate}
    \item \textbf{两层风险建模避免诊断泄漏}：针对高血脂标签与血脂指标100\%同源的问题，将模型拆分为现症识别层与未病预警层，避免了``用诊断依据预测诊断结果''的逻辑循环，使预警模型真正体现``治未病''价值。
    \item \textbf{动态逐月规划实现自适应降级}：问题3采用逐月模拟的动态规划方法，调理分级随痰湿积分下降自动降级，实现``随症加减''，在保证效果的同时节约后期过度医疗成本。
    \item \textbf{组合赋权降低主观不确定性}：风险评分权重采用熵权法客观赋权与专家经验主观赋权融合，较纯主观赋权降低了分层结果对权重选取的敏感度。
    \item \textbf{计算高效}：问题3决策空间仅30种组合，穷举法毫秒级求解；动态规划的逐月模拟状态空间可控，无需启发式算法。
\end{enumerate}

\subsection{模型缺点}
\begin{enumerate}
    \item \textbf{未病预警模型区分度有限}：排除血脂指标后，治未病预警模型的AUC仅约0.597，在独立测试集上区分高血脂与非高血脂人群的能力有限。这反映了当前非血脂指标对高血脂标签的解释力不足，也受限于数据的横截面设计。
    \item \textbf{线性假设局限}：Logistic回归假设logit与协变量呈线性关系，可能遗漏非线性交互效应（如痰湿积分与TG的乘积项）。本文虽引入随机森林进行补充验证，但未系统探索交互项。
    \item \textbf{干预效果参数未标定}：问题3中下降率公式（3\%/级、1\%/次）为题目给定假设，依从性衰减系数（0.5、0.6、0.8）基于老年医学一般性共识设定，均未基于随访数据标定，实际个体间差异可能显著。
    \item \textbf{动态规划未完全释放决策空间}：当前动态规划仅允许调理分级每月变化，活动强度$y$和频率$f$在6个月内仍保持固定。若允许$y$、$f$也逐月调整，理论上可进一步优化成本—效果比，但决策空间将扩大至$30^6$，需引入状态压缩或值迭代算法。此外，若允许$y$、$f$逐月调整，需引入月度间疲劳恢复模型，当前假设下跨月活动效果独立，尚不足以支撑完全动态决策。
\end{enumerate}

\subsection{模型改进方向}
\begin{enumerate}
    \item \textbf{引入CRITIC熵权法替代简单熵权}：当前熵权法仅考虑指标变异程度，CRITIC法同时考虑指标间的冲突性（相关性），可更全面地反映指标信息量，进一步提升赋权客观性。
    \item \textbf{系统探索非线性交互效应}：在Logistic回归中显式加入交互项（如痰湿积分$\times$TG、痰湿体质标签$\times$活动量表），或采用XGBoost的SHAP值进行全局解释，量化非线性贡献。
    \item \textbf{将确定性下降率改为Logistic饱和曲线}：当前下降率为线性公式$r(y,f)$，改进方向为引入$r(f)=r_{\max}/(1+e^{-k(f-f_0)})$，反映运动干预的边际递减效应；同时引入依从性概率$\pi(f)=\max(0,1-\lambda f)$，使模型更贴近临床实际。
    \item \textbf{扩展为完全动态规划}：允许活动强度$y$和频率$f$每月独立调整，采用带记忆化的递归搜索或值迭代算法，状态空间为（月份，当前积分，已用成本），理论上可找到全局最优的月度轨迹。
\end{enumerate}
